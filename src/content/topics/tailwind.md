Tailwind shows up across Sundae Club once the team wants utility-first styling without maintaining a large bespoke CSS codebase. Streams pair it with ViewComponent so each component owns its classes, and with Turbo so partial updates stay styled consistently.

You will see everything from `@apply` and shared patterns to forms on admin resources—plus a side journey into Figma libraries when design tooling and Tailwind tokens need to stay in sync. The ViewComponent + Tailwind episode is especially useful when you are wiring Hotwire frames around small, reusable UI pieces.

Use these moments if you are deciding how much CSS lives in components versus global layers, or if you want to watch Tailwind applied to real Rails screens rather than toy examples.
