Hotwire (Turbo and Stimulus) is how Sundae Club modernizes Rails HTML responses: full-page navigation gets faster, and targeted DOM updates replace hand-rolled AJAX for many admin workflows. Streams on the channel start with planning and dependency setup, then move into frames and streams on real screens like YouTube metadata editing.

The “ready to go” Hotwire episode covers removing Turbolinks, adding Turbo, and landing the first frame-based interactions. The Turbo Streams stream goes further into architecture, testing, and what breaks when assumptions about page state change.

Watch these segments if you want to see Hotwire introduced on a production-shaped Rails codebase—not a greenfield demo—and how ViewComponents slot into frame responses without a separate JSON API.
